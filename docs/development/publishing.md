# Publishing your Pack

Once your Pack is ready you can share it with others and publish it so it can be discovered. The available options depend on where your Pack will be used.

## Superhuman Docs Gallery

Packs that work with :superhuman-docs: Docs should be published to the [Gallery][gallery]. They can be discovered there, as well as within the product itself. See the following articles for more information:

- [Sharing & publishing][sharing_publishing]


## Superhuman Go Store

Connectors that work with :superhuman-go: Go should be published to the [Store][store]. They can be discovered there, as well as within the product itself. See the following articles for more information:

- [Listing & publishing][go_publishing]
